# B2315P 正式前端 legacy-static 风格调整设计

## 目标

在不改变 B2315P 已验证数据传输链路的前提下，调整正式 Vue 前端的页面外观，使其参考 `VUE-v2/legacy-static` 的深色监控台风格，并使用项目确定的产品名称。

## 已确认的边界

数据链路保持不变：

```text
手环 -> TCP 解析程序 0.0.0.0:8825 -> FastAPI 127.0.0.1:8000 -> PostgreSQL -> 前端查询 API
```

本次只修改正式前端源码，不修改：

- TCP 解析程序及其 systemd 服务；
- FastAPI 接口、字段、鉴权方式和响应结构；
- PostgreSQL 表结构、迁移和真实数据；
- `src/services/healthApi.js` 的 API 请求合同；
- `src/services/auth.js` 的 JWT 登录、退出和权限判断；
- `src/router.js` 的登录和页面路由机制。

## 页面设计

### 顶部栏

- 左侧只显示 `救援人员体能训练体征监测平台`；
- 删除 `B2315P`、运动员生命体征副标题、实时接收提示和数据源文字；
- 右侧保留当前登录用户、退出登录按钮和当前时间；
- 保持深蓝背景、青色强调线和响应式布局。

### 主导航

- 保留实时监控、设备管理、报警管理和健康数据；
- 将定位相关入口的显示名称调整为 `定位数据`；
- 不再提供睡眠功能入口；
- 定位入口仍打开已有定位页面，定位 API 不变；
- 设备、报警等子菜单仍根据现有角色权限显示。

### 实时监控首页

- 保留 legacy-static 风格的五项统计卡、设备卡片和深色配色；
- 设备数量、在线状态、心率、血氧、步数、体温、趋势数据继续从现有 API 读取；
- 未采集值显示 `--`，不填充示例数据；
- 报警统计仍以 API 返回值为准，接口不可用时显示 `--`；
- 维持当前十秒刷新机制。

### 其他页面

健康、健康详情、设备、报警、定位、角色、批量修改和设备指令页面保留原有功能，只统一公共标题、导航和颜色风格。睡眠页面不再从应用入口渲染。

## 实现范围

第一阶段只改：

```text
vue前端源码/vue-app/src/App.vue
vue前端源码/vue-app/src/style.css
```

如测试需要，允许同步调整与睡眠入口直接相关的前端测试或路由显示断言；不得修改后端代码。

`SleepView.vue` 文件先保留在源码中作为未使用文件，不从仓库删除，避免产生不可逆变更；应用不会导入、显示或导航到它。

## 验证标准

本地必须通过：

```text
pnpm test
pnpm run build
```

并人工检查：

1. 登录页仍可登录；
2. 退出登录仍回到登录页；
3. 不同角色的菜单权限仍然生效；
4. 首页显示云端真实设备数据；
5. 导航显示 `定位数据`，不显示睡眠入口；
6. 健康、报警、定位、设备设置和指令页面仍可进入；
7. 浏览器窄屏下标题、导航和卡片不重叠。

## 发布原则

本地测试和构建通过后生成新的 `dist` 发布包。云端发布前备份 `/var/www/b2315p/frontend/dist`，发布后执行 `nginx -t`、`/healthz` 和浏览器验收。出现问题时只恢复前端 `dist`，不重启或改动 TCP、FastAPI 和 PostgreSQL 服务。

## 非目标

- 不新增或修改健康、定位、报警、睡眠、导出、WebSocket 等 API；
- 不把 `VUE-v2` 原稿复制覆盖正式应用；
- 不把示例数值写入正式页面；
- 不将 PostgreSQL、FastAPI 或 TCP 端口暴露给浏览器。
